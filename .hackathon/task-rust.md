## What the demo must show (three minutes)

A recording is running with the Live Copilot on. A participant says a commitment ("I'll send the numbers to Wael by Monday", "let's get the deck to Naema", "we need to check the SIDRA thresholds"). Within a second a **Commitment caught** card appears in the recording companion's Copilot tab with the sentence, the owner and the deadline the detector found, and two buttons, **Approve** and **Dismiss**. Approve creates a task in the workspace and queues an agent run on the Local engine so a draft or brief exists before the recording stops (if agents are paused, the task is created and the card says "queued, agents paused"). The Workspaces tab shows the task with a **Live** chip. Nothing is created without the tap.

## Cross-layer contract

- **Detector (Rust, `src-tauri/src/copilot_session.rs`):** runs inside `on_caption` (`:1183`) beside the question detector, on confirmed captions only (`boundary == "silence"` closes the turn, as `detect_turn` does), on both channels. A commitment is a turn that matches one of `COMMITMENT_PATTERNS` and does not end with `?`. Patterns (case-insensitive, Rust regex, `&[&str]`):
  1. `^(i|i'll|i will|i can|i could|i'm going to|i am going to|let me)\s+(send|share|prepare|write|draft|check|look into|find out|book|schedule|set up|follow up|circulate|review|update|create|put together|get|ask|confirm)\b`
  2. `^(we'll|we will|we need to|we should|we have to|let's|lets)\s+(send|share|prepare|write|draft|check|look into|find out|book|schedule|set up|follow up|circulate|review|update|create|put together|get|ask|confirm)\b`
  3. `\b(action item|to[- ]?do|follow[- ]?up)\s*[:\-]\s*\S`
  Owner capture: `\b(to|for|with)\s+([A-Z][a-z]{2,})\b` → group 2 (else "Me" when the source is Me, else empty). Deadline capture: `\b(by|before|on)\s+(monday|tuesday|wednesday|thursday|friday|saturday|sunday|tomorrow|today|tonight|end of (the )?(day|week|month)|eod|eow|next week)\b` → the matched phrase. Dedup: the same normalized text within 60 s is ignored (reuse the auto-duplicate window logic).
- **In-memory commitments per session:** `CopilotSession.commitments: Vec<Commitment { id: u64, text, owner: Option<String>, deadline: Option<String>, source: String, at_ms: u64, state: "caught" | "approved" | "dismissed" }>`. Nothing is persisted until Approve.
- **Event `copilot-commitment`** (Tauri emit on catch and on every state change): `{ session_id: String, id: u64, text: String, owner: String | null, deadline: String | null, source: "Me" | "Them", at_ms: u64, state: "caught" | "approved" | "dismissed", task_id: i64 | null, run_queued: bool, agents_paused: bool }`.
- **Commands (`src-tauri/src/commands.rs`, registered in `lib.rs`):**
  - `commitment_approve(session_id: String, id: u64, capability: Option<String>) -> Result<CommitmentResult, String>` where `CommitmentResult { task: WorkspaceTask, run_queued: bool, agents_paused: bool }`. It resolves the workspace by the rule below, calls `storage::create_workspace_task(workspace_id, title, details, capability, source_meeting_id, None)`, then queues a run on the workspace's engine the same way the Workspaces tab queues one for a queued task (find the existing enqueue path in `workspace_runs.rs`; if `agents_paused` in config is true, do not queue and return `run_queued: false, agents_paused: true`). Title = the commitment text trimmed to 120 chars. Details = `Caught live during the meeting at <local HH:MM> from <source>.\nOwner: <owner or Me>. Deadline: <deadline or none>.\nSession: <session_id>` (the "Caught live" prefix is what the UI keys on). `capability` default: `"research"` when the verb is check, look into, find out, review, confirm, ask; else `"write"`. `source_meeting_id`: the meeting id of the current recording if the session has one, else `None` (do not add columns; backfill is out of scope today).
  - `commitment_dismiss(session_id: String, id: u64) -> Result<(), String>`.
  - Workspace rule: if a workspace exists whose name equals the recording folder's name (case-insensitive), use it; else use the workspace named `Live meetings`, creating it with engine `local` if missing (reuse `create_workspace` in storage).
- **Frontend (`src/`):** types `Commitment`, `CommitmentResult`; wrappers `commitmentApprove(sessionId, id, capability?)`, `commitmentDismiss(sessionId, id)`; listener for `copilot-commitment` scoped to the current session id; `CommitmentCard` rendered above the copilot cards in the Copilot tab (text, owner and deadline chips, Approve, Dismiss; after approve: `Task #<id> queued` plus `run started` or `agents paused`, and an `Open in Workspaces` link that switches to the Workspaces view); in `WorkspacesView.tsx`, a **Live** chip on any task whose details start with `Caught live`.
