# Settings redesign — implementation map

_Generated 2026-08-06 from an exhaustive read of all five existing settings tabs
(84 inventory entries → **74 controls placed**, `unmapped` empty). This is the
contract for the 8-section rebuild: **read it before writing any component.**
The prototype it implements:
https://claude.ai/code/artifact/398e713e-dd26-4a27-bbae-7f25a292133e_

> Why this doc exists: the download pipeline, the `configRef` mirror and the
> health check are ONE state machine spread across the tabs being split. Three
> of the new sections each need part of it. Cloning it per section is the
> obvious move and is wrong three ways (doubled IPC traffic, a split
> `activatingRef` so completions land on the wrong owner, and two config
> mirrors that clobber each other) — and it reintroduces the 2026-08-03
> cross-tab data-loss bug. Hoist to shared hooks.

`update` defers to the shell Save button; `persist` writes immediately. Converting an immediate control to deferred loses user settings; the reverse writes half-configured state to disk mid-edit.

- Whisper 'Use this one' — whisper_model — TranscriptionSection — hand-rolled immediate: getConfig() → updateConfig({...cfg, whisper_model: key}) → replaceConfig({...configRef.current, whisper_model: key}) [AiModelTab.tsx:214-228]. MUST stay immediate — the user already pressed Download; requiring a second Save press was judged a dead end. And the partial merge is the 2026-08-03 regression fix: handing the shell the whole disk copy wiped every unsaved edit in every other section (guarded by AiModelTab.test.tsx 'keeps unsaved Settings edits when a download finishes').
- 'Use this model' (notes profile switch) — ollama_model + llm_provider — NotesSection — immediate via set_local_model_profile (the Rust command rewrites config on disk), then replaceConfig merging ONLY the two fields registration.rs actually rewrote, onto configRef.current [AiModelTab.tsx:184-209]. - 'Enable calendar integration' — calendar.google.enabled — IntegrationsSection — persist() [TemplatesCalendarTab.tsx:465-472, handler 180-189]. THE most fragile: as update() a connected+enabled calendar silently reverts. It is also the only persist() consumer in that tab.
