# Phase 4 visual baselines

These screenshots are generated by `npm run test:e2e:baseline` from the
packaged Tauri debug application. The test normalizes WebDriver's physical
window pixels to the actual CSS viewport, including on Retina displays.

- `minimum-1024x720.png`: supported minimum CSS viewport; all six primary
  navigation tabs are asserted to be within the viewport with no document
  overflow.
- `wide-1440x900.png`: wide desktop layout.

The same smoke run asserts that the webview loads no remote HTTP(S) assets,
uses the bundled Inter font, and gives every visible native interactive
control an accessible name.
